이 폴더는 Claude Code가 이 저장소에서 작업할 때 `/prompt-engineering` 스킬로 자동 인식합니다.
프롬프트 초안을 붙여넣고 "이 프롬프트 다듬어 줘"라고 하면 진단 → 기법 선택 → 재작성 → 자기 검토 → 변경 내역 순서로 개선된 프롬프트를 돌려줍니다.

사이트(프롬프트 공방)의 점수 기준, 성공 기준 항목, 진행 방식 옵션, AI로 다듬기 지시문, 가이드의 "전문가 기법" 섹션은 이 스킬과 Anthropic의 Prompting best practices 문서를 바탕으로 작성했습니다.
